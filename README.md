# La Classe · Pro Farmer

classe.profarmer.it — agenti specializzati al servizio di un progetto (la prima classe: Riposa).

Questo repository contiene solo la pagina: niente dati né chiavi. Tutto arriva da Supabase dopo l'accesso
(e-mail, password e secondo fattore) e solo per i membri di una classe. Le risposte degli agenti le prepara
la funzione `classe` sul server. Progetto, regole di sicurezza e come si fa una classe nuova: nel repository
interno di Pro Farmer, cartella `Classe/`.
